# Contributing to ARK releases

This repository is ARK's **public distribution and support channel**, not the application source repository. Please do not submit application source code or proprietary patches here.

- Use **Issues** for reproducible bugs, documentation problems and feature ideas.
- Check the release version and platform before submitting a report.
- Remove API keys, personal information, private investigation data and sensitive logs.
- Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

The ARK core framework is intended to remain free to use with supported bring-your-own-key providers. Optional commercial AI services may be introduced separately.
