# Security policy

## Vulnerability reports

Please **do not disclose vulnerabilities in public GitHub issues**. Use GitHub's **Private vulnerability reporting** feature if it has been enabled for this repository. If it is not enabled, avoid posting vulnerability details publicly and use a verified private contact channel published by Arkspan Systems once available.

Include affected version, platform, reproduction steps, impact and relevant redacted diagnostics. Never transmit tokens, API keys or customer investigation evidence.

## Supported versions

No public ARK builds have been published. Supported-version information will be added when an official release exists.

## Disclosure

We aim to coordinate review, remediation and disclosure in a way that protects users. No fixed response SLA is currently advertised.
